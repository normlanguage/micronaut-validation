# Micronaut Validation

[English](README.md) | [简体中文](README.zh-CN.md)

[`micronaut.validation`](micronaut/validation/module.norm) binds the runtime and `@Validated` compile-time contract of Micronaut Validation 5.1.0. The [sample](samples/README.md) accepts a valid request and rejects an invalid one through HTTP.
